# Changelog

All notable changes to this project will be documented in this file.

## Versioning

This project follows **Semantic Versioning (SemVer)**:

```id="k2f9md"
MAJOR.MINOR.PATCH
```

* **MAJOR** → breaking changes (API changes, incompatible updates)
* **MINOR** → new features (backward-compatible)
* **PATCH** → bug fixes and small improvements

### Rules

* Latest version is always at the top
* Every release must be documented here
* Do not modify past versions after release
* Include release date in `YYYY-MM-DD` format
* Group changes under:

  * Added
  * Changed
  * Fixed
  * Removed
